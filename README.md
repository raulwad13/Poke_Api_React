# Pokédex React ⚡

Proyecto de aprendizaje creado con **React** y **Vite** para practicar componentes, organización de carpetas y consumo de datos relacionados con Pokémon.

## Tecnologías

- React 18
- Vite
- JavaScript (JSX)
- React Router
- Axios
- CSS y Sass

## Requisitos

- Node.js 18 o superior
- npm

## Instalación y ejecución

```bash
git clone https://github.com/raulwad13/Poke_Api_React.git
cd Poke_Api_React
npm install
npm run dev
```

Abre la dirección local que muestre Vite (habitualmente `http://localhost:5173`).

## Comandos

| Comando | Uso |
|---|---|
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Generar versión de producción |
| `npm run preview` | Previsualizar el build |
| `npm run lint` | Ejecutar ESLint |

## Estructura

- `src/App.jsx`: estructura principal.
- `src/components/Header/`: cabecera.
- `src/components/Main/`: contenido y componentes de Pokémon.
- `src/components/Footer/`: pie de página.
- `src/context/`: estado compartido.
- `src/styles/`: estilos adicionales.
